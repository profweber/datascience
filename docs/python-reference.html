Appendix A — Python Quick Reference

This appendix collects the Python functions used in this script, ordered by task – the question you have in mind (“How do I count the missing values?”) rather than the library. Each entry says what the function does, gives a short example and names where it is used first.

Notation: df is a DataFrame (a table), s a single column (a Series), m a mask of truth values. np, pd, plt and sns are the usual short names for NumPy, pandas, Matplotlib and seaborn (Chapter 1).

A.2 Missing values

Function What it does Example Used in
df.isna() True wherever a value is missing (NaN, None, NaT) df.isna().sum() counts missing values per column Ch. 2
df.notna() the opposite: True wherever a value is present t.notna().all() – are all values present? Ch. 2

Pitfall: is None, isna() and ==
  • x is None checks whether nothing was given, e.g. an optional argument of a function: if fname is None:. Use is only for None – for numbers and text always use ==.
  • s.isna() checks whether measured values are missing. Never test with == np.nan: NaN is by definition not equal to anything, not even to itself – np.nan == np.nan is False.
  • s == None on a column does not help either: it gives a mask in which even the missing values are False, and if s == None: raises an error.

Pitfall: and, or, not do not work on columns

Python’s and, or and not handle a single truth value. For masks – NumPy arrays and pandas columns – use &, | and ~, which work element by element, and put every condition in brackets:

single value mask (array, column)
and and &
or or \|
not not ~ 
df[(df["machine_id"] == "M4") & (df["shift"] == "night")]   # correct
df[df["machine_id"] == "M4" & df["shift"] == "night"]       # error: & binds before ==

not m on a mask raises an error (“the truth value of an array is ambiguous”), and ~True on a single value gives -2, because ~ is originally a bitwise operator on integers.

np.where with one argument

With three arguments, np.where(m, a, b) selects values. With only one argument, np.where(m) does something different: it returns the positions where m is True. For positions, np.flatnonzero(m) is clearer.

.str and .dt: functions for every entry of a column

Text functions such as strip() work on a single text. To apply them to every entry of a column, pandas offers the accessor .str: s.str.strip(), s.str.lower(), s.str.startswith("produkt"). The column must contain text – hence s.astype(str).str.strip(). In the same way, .dt gives access to the parts of time stamps: s.dt.hour, s.dt.day_name(). For a time index, these are available directly: df.index.hour, df.index.dayofweek.

Pitfall: some functions exist twice with different meanings.

s = pd.Series(["1,5", "2,0"])
s.replace(",", ".")        # replaces entries that are exactly "," – here: no change
s.str.replace(",", ".")    # replaces "," inside every text – "1.5", "2.0"

Forgetting .str raises no error – the data simply remain unchanged.

Format codes for time stamps

In pd.to_datetime(s, format=...), every code stands for one complete field of the date; its length is part of its definition:

Code Meaning Digits Example
%Y year 4 2025
%y year without century 2 25
%m month 2 04
%d day 2 11
%H hour (00–23) 2 13
%M minute 2 05
%S second 2 00

All other characters (-, ., :, blanks) must appear in the format exactly as in the data. Upper and lower case matter: %m is the month, %M the minute – a classic error that often raises no error message. Other tools write formats differently, e.g. YYYYMMDDHH in Excel, databases or the DWD documentation; such formats have to be translated.

Formats you will meet in practice:

Data look like Typical source Reading in pandas

11.04.2025 13:00 German software, Excel exports format="%d.%m.%Y %H:%M"
