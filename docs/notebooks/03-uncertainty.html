3  Probability and Uncertainty

Every measurement and every estimate carries uncertainty. Engineers need to quantify it – for tolerances, for safety factors and for maintenance planning.

Engineering question: How long does a jet engine run before it fails, and how certain are we about that estimate?

Learning goals. After this chapter you can

  • describe data with probability distributions (normal, lognormal, Weibull),
  • fit a distribution to lifetime data and check the fit with a probability plot,
  • compute confidence intervals analytically and with the bootstrap,
  • derive reliability measures such as the B10 life,
  • apply Bayes’ theorem to diagnostic alarms and explain the base rate effect,
  • update prior knowledge with test data (beta–binomial model) and interpret a credible interval.

Datasets in this chapter

  • NASA C-MAPSS turbofan degradation data

3.1 Distributions for engineering data

Distribution Typical use
Normal measurement errors, dimensions of machined parts
Lognormal particle sizes, repair times, fatigue life
Weibull lifetimes, strength of brittle materials
Exponential random failures with constant failure rate
Poisson number of defects per unit

The two-parameter Weibull distribution has the cumulative distribution function

\[F(t) = 1 - \exp\left[-\left(\frac{t}{\eta}\right)^{\beta}\right]\]

with shape parameter \(\beta\) and scale parameter \(\eta\). \(\beta < 1\) indicates early failures, \(\beta = 1\) random failures, \(\beta > 1\) wear-out.

3.2 Live coding: lifetimes of turbofan engines

C-MAPSS contains simulated run-to-failure trajectories of turbofan engines. In the training file train_FD001.txt every one of the 100 engines runs until failure, so the last cycle of each engine is its lifetime.

Data access. Download CMAPSSData.zip from the NASA Open Data Portal (link above) and extract it into the folder data/CMAPSSData/. In Colab, upload the zip file via the file browser and run the cell below.

from pathlib import Path
import zipfile

DATA = Path("data")
if Path("CMAPSSData.zip").exists() and not (DATA / "CMAPSSData").exists():
    zipfile.ZipFile("CMAPSSData.zip").extractall(DATA / "CMAPSSData")

cols = ["unit", "cycle", "op1", "op2", "op3"] + [f"s{i}" for i in range(1, 22)]
train = pd.read_csv(DATA / "CMAPSSData" / "train_FD001.txt", sep=r"\s+", header=None, names=cols)
lifetimes = train.groupby("unit")["cycle"].max()
lifetimes.describe()
beta, loc, eta = stats.weibull_min.fit(lifetimes, floc=0)
print(f"Weibull fit: shape beta = {beta:.2f}, scale eta = {eta:.1f} cycles")

fig, axes = plt.subplots(1, 2, figsize=(11, 4))
t = np.linspace(0, lifetimes.max() * 1.1, 300)
axes[0].hist(lifetimes, bins=15, density=True, alpha=0.6, label="data")
axes[0].plot(t, stats.weibull_min.pdf(t, beta, scale=eta), label="Weibull fit")
axes[0].set(xlabel="Lifetime (cycles)", ylabel="Density"); axes[0].legend()
stats.probplot(lifetimes, dist=stats.weibull_min, sparams=(beta, 0, eta), plot=axes[1])
axes[1].set_title("Probability plot (Weibull)")
plt.show()
# B10 life: 10 % of the engines have failed
b10 = stats.weibull_min.ppf(0.10, beta, scale=eta)
print(f"B10 life: {b10:.0f} cycles")

# 95 % confidence interval of the mean lifetime: t-interval vs. bootstrap
ci_t = stats.t.interval(0.95, df=len(lifetimes) - 1,
                        loc=lifetimes.mean(), scale=stats.sem(lifetimes))
boot = stats.bootstrap((lifetimes.values,), np.mean, confidence_level=0.95,
                       random_state=0)
print("t-interval:        ", np.round(ci_t, 1))
print("bootstrap interval:", np.round(boot.confidence_interval, 1))

3.3 Bayes’ theorem: how much should we trust an alarm?

Bayes’ theorem reverses a conditional probability:

\[P(F \mid A) = \frac{P(A \mid F)\,P(F)}{P(A \mid F)\,P(F) + P(A \mid \bar F)\,P(\bar F)}\]

Example: a condition monitoring system detects a bearing fault \(F\) with probability \(P(A \mid F) = 0.95\) (sensitivity) and raises a false alarm on a healthy bearing with \(P(A \mid \bar F) = 0.05\). Only 1 % of the monitored bearings are actually damaged. If the system raises an alarm \(A\), how likely is a real fault?

\[P(F \mid A) = \frac{0.95 \cdot 0.01}{0.95 \cdot 0.01 + 0.05 \cdot 0.99} \approx 0.16\]

Five out of six alarms are false – not because the system is bad, but because faults are rare. This base rate effect returns in Chapter 7 (precision of a classifier).

sens, false_alarm = 0.95, 0.05
prevalence = np.logspace(-4, -0.3, 200)
posterior = sens * prevalence / (sens * prevalence + false_alarm * (1 - prevalence))

plt.semilogx(prevalence, posterior)
plt.axvline(0.01, ls=":", c="k")
plt.xlabel("Share of damaged bearings P(F)"); plt.ylabel("P(fault | alarm)")
plt.title("Same sensor, very different meaning of an alarm")
plt.show()

3.4 Bayesian estimation: combining prior knowledge with few tests

Frequentist statistics uses only the current data. Bayesian statistics treats an unknown parameter \(\theta\) as uncertain and updates a prior distribution with the data to a posterior distribution:

\[p(\theta \mid \text{data}) \propto p(\text{data} \mid \theta)\; p(\theta)\]

Engineering example: a new product variant is tested, 3 of 50 parts are defective. From the predecessor product we know a defect rate of about 2 %. For a defect rate, the beta distribution is a convenient prior: with prior \(\text{Beta}(\alpha, \beta)\) and \(k\) defects in \(n\) parts, the posterior is simply \(\text{Beta}(\alpha + k,\; \beta + n - k)\). The prior \(\text{Beta}(2, 98)\) has mean 2 % and carries roughly the weight of 100 previously inspected parts.

k, n = 3, 50                       # new tests: defects, parts
a0, b0 = 2, 98                     # prior from the predecessor product
a1, b1 = a0 + k, b0 + n - k        # posterior

p = np.linspace(0, 0.20, 500)
plt.plot(p, stats.beta.pdf(p, a0, b0), label="prior (predecessor)")
plt.plot(p, stats.beta.pdf(p, 1 + k, 1 + n - k), label="data only (flat prior)")
plt.plot(p, stats.beta.pdf(p, a1, b1), label="posterior")
plt.xlabel("Defect rate"); plt.ylabel("Density"); plt.legend()
plt.show()

ci_freq = stats.binomtest(k, n).proportion_ci(0.95)
print(f"Frequentist: {k/n:.1%}, 95 % CI [{ci_freq.low:.1%}, {ci_freq.high:.1%}]")
lo, hi = stats.beta.interval(0.95, a1, b1)
print(f"Bayesian:    {a1/(a1+b1):.1%}, 95 % credible interval [{lo:.1%}, {hi:.1%}]")
